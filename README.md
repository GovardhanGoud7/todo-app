# To-Do List App

A simple command-line to-do list written in Python. Your tasks are saved between sessions.

## Features
- Add tasks
- View all tasks with numbers
- Mark tasks as done
- Delete tasks
- Tasks saved automatically in `tasks.json`

## How to run
1. Install Python 3
2. Download `todo app.py`
3. Run: `python "todo app.py"`

## How to use
Type a number from the menu (1 to 5) and follow the prompts. Choose 5 to quit.

## Example
```
1) Add task   2) View tasks   3) Mark done   4) Delete task   5) Quit
Your choice: 1
Task: Buy milk
  Added: Buy milk
```
